The client application enabled some debug logging by default, this helps with debugging incase something happens.<br/>
However, ALL logging can be turned off in the UI, both the Browser Console logging and the application itself.<br/>
**Our stance on logging is that is the user should always be able to turn it off completely, we even keep our website free of analytics and cookies.**<br/>
The VPN server also has a `--silent` flag to disable all logging.

---

# How To Disable Logging

When all logging options are turned off, the app will not log to file or to console.<br/>
This applies to the UI as well.

```md
1. Go to `Application`
2. Go to `General Settings`
3. Unckeck all the logging options
```

---

# Enable Debug Logging

```md
1. Go to `Application`
2. Go to `General Settings`
3. Check the logging option you want to be enabled
```

### Logging options

```md
- Debug Logging
   Controls all application logging (DNS queries, connections, errors, etc.)
   This is the primary logging toggle. When disabled, no logs are written to file or console.

- Console Logging
   Enables logging to `stdout`/console.

- Debug Mode
   Enables javascript console logging for `UI` debugging.
```

:::note

All application logging is controlled by the `DebugLogging` setting (or the `--debug` CLI flag). The `InfoLogging` and `ErrorLogging` fields exist in the config but have no effect.

:::
