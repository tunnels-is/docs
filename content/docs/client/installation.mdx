# Download
Visit [the download page](https://tunnels.is/download) on the tunnels website and download the client for your platform.

---

# Run the client

### Linux
```bash
  # Tunnels will ask for network admin permissions the first time you run it.
  ./tunnels 
```

### MacOS
```bash
 sudo ./tunnels
```

### Windows
`Shift-RightClick` the `tunnels.exe` and select `Run As Administrator`

# Optional linux configurations

## Linux systemd Service

Create `/etc/systemd/system/tunnels.service`:

```ini
[Unit]
Description=Tunnels  Client
Before=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/tunnels
ExecStart=/opt/tunnels/tunnels
Restart=always
RestartSec=10
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

## Controls

```bash
sudo systemctl daemon-reload
sudo systemctl disable tunnels
sudo systemctl enable tunnels
sudo systemctl start tunnels

# View logs
sudo journalctl -u tunnels -f
```
