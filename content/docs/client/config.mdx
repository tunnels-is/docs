# Directory Structure

Tunnels uses the following directory structure:

```md
<basePath>/
├── tunnels.conf              # Main configuration file
├── tunnel/                   # Tunnel configurations
│   ├── tunnels.conf          # Default tunnel
│   └── <name>.conf           # Additional tunnels
├── users/                    # User auth files (UI mode only)
├── logs/                     # Log files
│   └── YYYY-MM-DD.log
├── blocklists/               # DNS blocklists
└── whitelists/               # DNS whitelists
```

---

# Available CLI Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--version` | Show version and exit | - |
| `--basePath <path>` | Directory for config and log files | Executable directory |
| `--tunnelType <type>` | Tunnel type: `default` or `iot` | `default` |
| `--debug` | Enable debug logging | `false` |
| `--requireConfig` | Exit if config file is missing (don't auto-generate) | `false` |
| `--tls` | Enable TLS for the local API server (HTTPS) | `false` |

### Examples

```bash
# Show version
./tunnels --version
# Run with custom config directory
./tunnels --basePath /opt/tunnels
# Create an IoT compatible config
./tunnels --tunnelType iot
# Enable debug mode
./tunnels --debug
# Exit with error if config file does not exist
./tunnels --requireConfig
# Enable HTTPS for local API server
./tunnels --tls
```

# Client Config with comments
:::warning

Do do not copy this config, tunnels does not support comments in the configuration <br/>There is a clean config for copying a bit further down

:::

```json
{
    "OpenUI": false, // Enable/Disable opening the UI on client start

    // Control servers define the authentication and control endpoints
    "ControlServers": [
        {
            "ID": "tunnels", // Unique identifier for this control server
            "Host": "api.tunnels.is", // Control server hostname
            "Port": "443", // Control server port
            "CertificatePath": "", // Optional path to custom certificate for validation
            "ValidateCertificate": true // Enable/Disable certificate validation
        }
    ],

    "DisableBlockLists": false, // Completely disable DNS blocklist functionality

    // CLI specific configuration (only used in CLI mode)
    "CLIConfig": {
        "ControlServerID": "tunnels", // Which control server to use from ControlServers list
        "DeviceToken": "", // Device authentication token
        "UserID": "", // User ID (alternative to DeviceToken)
        "ServerID": "", // Default server to connect to
        "SendStats": false, // Enable/Disable sending statistics to server
        "PinVersion": false, // Lock to a specific client version
        "SkipUpdatePrompt": false // Skip prompting for updates
    },

    // Update settings
    "AutoDownloadUpdate": true, // Automatically download updates when available
    "ExitPostUpdate": false, // Exit application after updating
    "RestartPostUpdate": false, // Restart application after updating
    "UpdateWhileConnected": false, // Allow updates while connected to VPN
    "UpdateCheckInterval": 1440, // How often to check for updates (in minutes)
    "DisableUpdates": true, // Completely disable update functionality

    // API settings for local client API
    "APIIP": "127.0.0.1", // IP address for the local API server
    "APIPort": "7777", // Port for the local API server
    "APICert": "./api.crt", // Path to API server certificate
    "APIKey": "./api.key", // Path to API server private key
    "APICertDomains": ["tunnels.app", "app.tunnels.is"], // Domains to include in API certificate
    "APICertIPs": ["127.0.0.1", "0.0.0.0"], // IP addresses to include in API certificate
    "APICertType": 0, // Certificate key type (0 = RSA, 1 = ECDSA)

    // Generic settings
    "DisableDNS": false, // Completely disable DNS functionality

    // Logging settings
    "LogBlockedDomains": true, // Log domains that are blocked by DNS blocklists
    "LogBlockedPorts": false, // Log ports that are blocked
    "LogAllDomains": true, // Log all DNS queries (generates large logs)
    "DebugLogging": true, // Enable debug level logging
    "ConsoleLogging": false, // Output logs to console
    "InfoLogging": true, // Enable info level logging
    "ErrorLogging": true, // Enable error level logging
    "ConsoleLogOnly": false, // Only log to console, not to file
    "ConnectionTracer": false, // Enable detailed connection tracing (for debugging)
    "BandwidthGraphs": true, // Track per-second bandwidth history for graphs

    // DNS settings
    "DNS1Default": "1.1.1.1", // Primary default DNS server
    "DNS2Default": "8.8.8.8", // Secondary default DNS server
    "DNSOverHTTPS": false, // Use DNS over HTTPS for upstream queries
    "DNSstats": true, // Enable DNS statistics collection
    "DNSServerIP": "127.0.0.1", // IP address for local DNS server
    "DNSServerPort": "53", // Port for local DNS server

    // DNS Blocklists - Protect against malicious domains
    // The app will populate this list at runtime.
    // Custom blocklists can be added here or using the UI.
    "DNSBlockLists": [],

    // DNS Whitelists - Domains that should never be blocked
    // Custom whitelsits can be added here or using the UI.
    "DNSWhiteLists": [
        {
            "Tag": "my-white-list", 
             // Optional URL to download whitelist from.
             // If empty, tunnels will load a file from the `whitelist` dir: ./whitelists/my-white-list 
            "URL": "", 
            "Enabled": true,
        }
    ],

    // Custom DNS records ( resolvable at all times, even while disconnected )
    "DNSRecords": [
        {
            "Domain": "example.com",
            "Wildcard": false, // Allow subdomain matching (*.example.com)
            "IP": ["10.0.0.100"], // `A` record responses
            "TXT": [] // `TXT` record responses
        }
    ]
}
```
