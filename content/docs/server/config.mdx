# Overview

The Tunnels server requires a configuration file to define network settings, features, authentication, and VPN parameters. This configuration controls how the server operates, including bandwidth allocation, port ranges, DNS settings, and security options.

The server configuration file is typically located in the same directory as the server executable or can be specified via the `--configPath` flag. The server supports JSON (`.json`), YAML (`.yaml`, `.yml`) configuration formats.

## Configuration Files

The server requires the following files:

```
<serverPath>/
├── config.json           # Main server configuration file (or .yaml/.yml)
```

# Config with comments
:::warning

Use the clean config below for copying, the server does not support comments in the config

:::
```json
{
    "Features": [
        "LAN", // Enables WAN over LAN
        "VPN", // Enables Generic VPN functionality
        "AUTH", // Enables the authentication control unit
        "DNS", // Enables DNS features (reserved, not yet active at runtime)
        "BBOLT" // Enables bbolt embedded database (recommended for most users)
    ],
    "LogAPIHosts": false, // Enable logging of API client hostnames

    // VPN Configuration
    "VPNIP": "192.168.1.32", // The IP address used for VPN traffic
    "VPNPort": "444", // The port used for VPN traffic

    // API Configuration
    "APIIP": "192.168.1.32", // The IP address used for API calls
    "APIPort": "443", // The port used for API calls

    // Port Range Configuration (VPN feature)
    "StartPort": 2000,
    "EndPort": 65530,
    // StartPort and EndPort define the port range which the VPN feature will use
    // when communicating with the internet or subnets

    // Bandwidth and Resource Allocation
    "ServerBandwidthMbps": 1000, // The available bandwidth on this server
    "UserBandwidthMbps": 10, // Per user bandwidth allocation (not a hard cap)
    // The maximum number of clients per server is calculated using the bandwidth fields
    // ServerBandwidthMbps/UserBandwidthMbps = MaximumUsers
    // Each user is allocated ports based on the available port range
    // (EndPort-StartPort)/MaximumUsers = PortsPerUser
    // This is how tunnels ensures even port distribution for all users

    // Client Connection Settings
    "UserMaxConnections": 10, // The maximum number of connections each client can have
    "InternetAccess": true, // Enables/Disables internet access from the server (VPN feature only)
    "LocalNetworkAccess": false, // Enables/Disables local network (subnet) access from the server (VPN feature only)

    // DNS Configuration
    // Define custom DNS records that will be delivered to the client on connection
    "DNSRecords": [
        {
            "Domain": "mydomain.com",
            "Wildcard": true, // Allows for any subdomain to be resolved to the IP or TXT records (e.g., blog.mydomain.com)
            "IP": ["10.10.0.2", "10.10.0.3"],
            "TXT": ["This is a text record", "This is another text record"]
        }
    ],
    "DNSServers": ["1.1.1.1", "9.9.9.9"], // Custom DNS servers that will be applied client-side on connection

    // Security and Secrets Configuration
    // Secrets can be stored in environment variables or in the configuration file itself
    // If SecretStore is set to "env", secrets will be read from environment variables
    // with the same names as the fields in this configuration
    "SecretStore": "config", // Options: "env" | "config" (defaults to "env" if omitted)
    "DBurl": "", // Only used if MongoDB is configured as the default database
    "TwoFactorKey": "1f9890c7b1e94365ab8f65d0e3d41bb4", // Encryption key used for storing two factor authentication
    "PayKey": "", // Payment/billing integration key (optional)
    "CertPem": "./cert.pem", // Public certificate for this VPN server
    "KeyPem": "./key.pem", // Private key for this VPN server
    "CertPems": ["./cert.pem","./cert2.pem"], // Use this field to load additional certificates for the API
    "KeyPems": ["./key.pem","./keyw.pem"], // Use this field to load additional certificates for the API
    "SignPem": "./sign.pem", // Public signing certificate from the controller
    // This allows the server to validate that connection attempts have been processed by the correct control server

    // Administration and Management
    "Hostname": "tunnels.local", // Base hostname used for DHCP assignments
    "PingTimeoutMinutes": 2, // How many minutes it takes to time out a client connection (minimum: 2)
    "DHCPTimeoutHours": 1, // How many hours until DHCP assignments are released (minimum: 1)
    "NetAdmins": [], // SHA3-256 hashed identifiers of network administrators (use --admin flag to add)
    "AdminAPIKey": "0cd1f6c4-9b98-4bda-860c-0c04f103c84d", // API key for administrative control server access
    "ClientVersion": "", // Enforce specific client version for all devices (empty = no enforcement)
    // More details can be found in the "Updating Device Clients" guide

    // Network Configuration
    // LAN network used for WAN over LAN (modification not recommended)
    "Lan": {
        "Tag": "lan",
        "Network": "10.0.0.0/16",
        "Nat": "" // Optional network NAT (f.x. 11.0.0.0/16)
    },
    "DisableLanFirewall": false, // Disable firewall for LAN network (allows all LAN traffic without restrictions)

    // Routes applied to clients on connection
    "Routes": [
        {
            "Address": "10.0.0.0/16", // LAN default route (required if LAN feature is enabled)
            "Metric": "0", // Optional metric for the route
            "Gateway": "" // Optional gateway for the route (empty = use default gateway)
        }
    ],

    // Subnet Configuration (VPN feature)
    // Define additional subnets available outside the default VPN network
    // SubNets are required when applying network NAT configurations
    "SubNets": [
        {
            "Tag": "subnetX",
            "Network": "10.10.0.0/16",
            "Nat": "" // Optional network NAT (e.g., 11.11.0.0/16)
        }
    ]

}
```
