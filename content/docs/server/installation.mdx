# Installing the server

1. **Download the server**
   ```bash
    curl -L -O $(curl -s https://api.github.com/repos/tunnels-is/tunnels/releases/latest | grep 'browser_download_url' | grep 'server_.*_Linux_amd64.tar.gz' | cut -d '"' -f 4)
   ```

2. **Extract and place the binary**
   ```bash
   sudo mkdir -p /opt/tunnels
   sudo tar -xzf server_*_Linux_amd64.tar.gz -C /opt/tunnels
   ```

3. **Run the server with auto-configuration**
   ```bash
   cd /opt/tunnels
   ./tunnels --config
   ```

   This generates a `config.json`, TLS certificates (`cert.pem`, `key.pem`), and starts the server.

:::danger

The admin username is `admin` and the password is randomly generated on first start. The password is printed to the server logs. You must set up two-factor authentication before you can reset the password through the client GUI.

Do not open any ports to the server before changing the password.

:::

# Available CLI Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--version` | Show version and exit | - |
| `--config` | Generate config and certificates, then start the server | `false` |
| `--configPath <path>` | Path to config file (supports .json, .yaml, .yml) | `./config.json` |
| `--certs` | Generate certificates only and exit | `false` |
| `--admin <identifier>` | Add an admin identifier to NetAdmins | - |
| `--logLevel <level>` | Set log level: debug, info, warn, error | `debug` |
| `--json` | Enable JSON structured logging | `true` |
| `--source` | Disable source line information in logs | `false` |
| `--silent` | Disable all logging | `false` |

---

4. **Inspect the configuration**
   ```bash
   cat /opt/tunnels/config.json
   ```
   For detailed configuration options, see the [server configuration guide](/docs/server/config).
